# Accessibility release checklist

Target: WCAG 2.2 Level AA. The ADA does not provide a single technical website standard for private businesses, so WCAG 2.2 AA is used as the measurable engineering target alongside effective-communication review.

- [x] Page language and unique titles
- [x] One main landmark and ordered headings per page
- [x] Skip link and logical keyboard order
- [x] Four-pixel visible focus indicator
- [x] Body copy starts at 19–20px with generous line spacing
- [x] Larger-text control in the lesson
- [x] Controls at least 48px high where practical
- [x] No information conveyed by color alone
- [x] No time limits, autoplay, flashing content, or drag-only interaction
- [x] Reduced-motion and forced-colors styles
- [x] Responsive single-column reflow below 900px and 620px
- [x] Plain-language safety and privacy notices
- [x] No cognitive-function test required by the training
- [ ] Automated axe/WAVE scan on the deployed URL
- [ ] Screen-reader smoke tests with NVDA + Chrome and VoiceOver + Safari
- [ ] 200% and 400% zoom review on the deployed URL
- [ ] User review with people 65+ and people who use assistive technology
- [ ] Recheck approved ID.me asset rendering and alternative text after deployment
