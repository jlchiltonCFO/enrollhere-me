# Security

EnrollHere.me is training only. It has no account system, credential fields, uploads, contact forms, analytics, advertising trackers, or payment tools.

## Reporting a concern

Report security concerns to JLC Limited through its official business contact channel. Do not include a password, security code, Social Security number, or identity document in a report.

## Safety rules for future changes

- Never add fields that collect an ID.me password, one-time code, Social Security number, or identity document.
- Treat a real ID.me integration as a separate security and privacy release.
- Review external links, dependencies, privacy text, terms, and accessibility before each public release.
- Keep secrets and private keys outside the repository.
